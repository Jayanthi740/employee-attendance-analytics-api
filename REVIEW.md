## Review Approach

The implementation should be checked for:

* Consistency with the API contract.
* Correct IST and overnight-shift handling.
* Correct late-arrival grace-period and rounding behavior.
* Correct attendance status calculations.
* Employee identifier uniqueness and data integrity.
* Attendance correction history.
* MongoDB connection failures and error handling.
* Pagination limits and analytics accuracy.
